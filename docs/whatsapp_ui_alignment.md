# WhatsApp UI Alignment – Phase 0 Deliverables

## 1. Reference Capture Checklist
Use هذه القائمة لجمع لقطات الشاشة وتسجيلات الفيديو قبل البدء بالتنفيذ. احرص على تغطية إصدار Android وآخر نسخة ويب.

| التبويب / الشاشة | Android (لقطة + فيديو قصير) | Web (لقطة + فيديو قصير) | ملاحظات يجب التقاطها |
| --- | --- | --- | --- |
| شاشة البداية / قائمة الدردشات | ☐ | ☐ | App Bar، زر البحث، زر الكاميرا، الرسائل المثبتة، زر بدء محادثة |
| غرفة الدردشة | ☐ | ☐ | قائمة الخيارات (رد، إعادة توجيه، تثبيت، حذف)، فقاعات الرسائل، شريط الإدخال، المؤشر في الأسفل |
| شاشة المجموعات / المجتمعات | ☐ | ☐ | طريقة عرض المجتمعات، القنوات، خيارات الإدارة |
| شاشة الحالات (Stories) | ☐ | ☐ | عرض الحالات، زر My Status، واجهة عرض الحالة |
| شاشة المكالمات | ☐ | ☐ | سجل المكالمات، زر الاتصال الجديد، واجهة المكالمة الجارية |
| صفحة الإعدادات | ☐ | ☐ | رأس الصفحة، الأقسام المختلفة، صفحات فرعية (خصوصية، التخزين، الأجهزة المرتبطة) |
| شاشة البحث / بدء محادثة جديدة | ☐ | ☐ | الحقول المقترحة، نتائج البحث، التصفية |
| شاشة معلومات الدردشة / المجموعة | ☐ | ☐ | قائمة الأعضاء، الوسائط المشتركة، الإعدادات الخاصة بالمجموعة |

> **كيفية الاستخدام**: ضع علامة (✅) بعد التقاط كل عنصر واحفظ الملفات في مجلد مشترك (`/docs/references/whatsapp/` مثلاً) مع تسمية واضحة.

## 2. خريطة الملفات الحالية في عرب شات
يعرض الجدول التالي الملفات الأساسية، حالة الواجهة، وما إذا كانت بحاجة إلى إعادة تصميم أو إعادة استخدام.

| الملف / القالب | الوظيفة الحالية | الحالة بالنسبة لخطة المطابقة | ملاحظات |
| --- | --- | --- | --- |
| `templates/base.html` | الحاوية العامة + شريط سفلي | **إعادة تصميم كاملة** | سيُستبدل بهيكل App Bar + Tabs مشابه لواتساب |
| `templates/chat/private_chats.html` | قائمة الدردشات | **تحوير كبير** | دمج مع التخطيط الجديد، إضافة الرسائل المثبتة، خيارات محسّنة |
| `templates/chat/chat_room.html` | غرفة الدردشة | **تحسين وتعديل** | مطابقة قائمة الخيارات، دعم تثبيت الرسائل، ضبط الشريط السفلي |
| `templates/chat/groups.html` | واجهة المجموعات | **إعادة تصميم كاملة** | تحويلها لتبويب "Community" مع التسلسل الهرمي الصحيح |
| `templates/chat/stories.html` | واجهة القصص | **تحوير متوسط** | نقلها إلى تبويب الحالات، تبسيط العرض |
| `templates/chat/search.html` | البحث عن الأصدقاء | **تحوير متوسط** | دمج مع شاشة البحث العالمية كما في واتساب |
| `templates/chat/settings.html` | صفحة الإعدادات | **إعادة تصميم كاملة** | تحويلها لنمط واتساب مع صفحات فرعية |
| `templates/chat/dashboard.html` | صفحة ترحيبية | **إلغاء / دمج** | لن تكون موجودة في النسخة المطابقة (الدخول مباشرة إلى الدردشات) |
| `templates/chat/create_group.html` | إنشاء مجموعة | **تحسين واجهة** | محاكاة نموذج واتساب للإنشاء (قائمة أصدقاء، إعدادات الخصوصية) |
| `templates/chat/web_views.py` | معالجات الويب | **تحديث متزامن** | سيعاد تنظيم البيانات لتلبية المتطلبات الجديدة (مجتمعات، مكالمات) |

## 4. قصص المستخدم الأساسية (MVP لمطابقة واتساب)
تم جمعها لضمان تغطية جميع التجارب الرئيسة. يمكن تحويل كل بند إلى بطاقة مهمة لاحقًا.

1. **كمستخدم** أريد رؤية قائمة الدردشات بتسلسل واتساب (المثبتة، المقروءة، الوقت، معاينة الرسالة، مؤشر القراءة) لأجد المحادثات بسرعة.
2. **كمستخدم** أريد الدخول إلى محادثة والقيام بكل الإجراءات المتاحة في واتساب (رد، إعادة توجيه، تثبيت، تحديد متعدد، حذف) مع عرض مطابق للرسائل المرسلة والمستقبلة.
3. **كمستخدم** أريد إنشاء مجموعات والانضمام إلى مجتمعات من خلال تبويب موحّد يوفر خيارات الإدارة نفسها.
4. **كمستخدم** أريد استعراض الحالات ورفع حالة جديدة داخل تبويب مخصص يشبه تجربة واتساب.
5. **كمستخدم** أريد الاطلاع على سجل المكالمات وإجراء مكالمات صوتية أو فيديو من تبويب المكالمات.
6. **كمستخدم** أريد الوصول إلى إعدادات الحساب، الخصوصية، الإشعارات، التخزين، والأجهزة المرتبطة من صفحة إعدادات مطابقة لنظيرتها في واتساب.
7. **كمستخدم** أريد استخدام شريط البحث العالمي للعثور على جهات الاتصال أو الرسائل كما في واتساب.
8. **كمشرف مجموعة/مجتمع** أريد إدارة الأعضاء، تعيين المشرفين، عرض الوسائط المشتركة، وضبط إعدادات الدعوات بنفس أسلوب واتساب.

> يمكن إضافة قصص فرعية (مثلاً تثبيت رسالة معينة، أو تغيير خلفية الدردشة) عند الدخول في مراحل التنفيذ.
